# Путь кластера — вебинар о платформе

Интерактивная HTML-презентация о создании Kubernetes-кластера: от `ClusterClaim` и подготовки инфраструктуры до готового L2 и приложений пользователя. Основной вариант — **[platform-beget.html](outputs/platform-beget.html)**, оформленный в стилистике Beget с космическим фоном. Рассказ рассчитан на 10–15 минут: 7 глав, 36 событий, ручное переключение шагов.

[Сценарий и заметки ведущего](outputs/platform-beget-guide.md) · [Предпросмотр](outputs/platform-beget-preview.png)

## Быстрый запуск

Для разработки и сборки нужны **Node.js `^22.18.0 || >=24.0.0`**, npm и современный браузер. Для клонирования — Git и доступ к репозиторию через SSH.

```bash
git clone git@github.com:PRO-Robotech/platform-webinar.git
cd platform-webinar
npm ci
npm run dev
```

Откройте в браузере **[http://127.0.0.1:5173/](http://127.0.0.1:5173/)**. Vite следит за изменениями исходников и обновляет страницу во время разработки. Чтобы остановить сервер, нажмите `Ctrl+C` в его терминале.

Если порт 5173 уже занят, укажите другой:

```bash
npm run dev -- --port 5174
```

Тогда адрес презентации будет [http://127.0.0.1:5174/](http://127.0.0.1:5174/).

**Без Node.js и сервера:** готовый файл `outputs/platform-beget.html` можно открыть напрямую в браузере. Стили, скрипты, логотип и шрифты встроены в HTML; для показа этого файла подключение к интернету не требуется. Репозиторий содержит готовую сборку, поэтому пересобирать её перед первым показом не нужно.

Приложение написано на TypeScript и использует Vite без UI-фреймворка и backend. Node.js нужен только для разработки и сборки; результат — обычные HTML, CSS и JavaScript.

## Управление

| Действие | Управление |
| --- | --- |
| Следующее событие | `→`, `PageDown`, пробел или кнопка перехода вперёд |
| Предыдущее событие | `←`, `PageUp` или кнопка перехода назад |
| Перейти к главе | Клавиши `1`–`7` или название главы в нижней панели |
| Выбрать событие внутри главы | Точки навигации в нижней панели |
| Открыть описание блока | Нажатие на блок; с клавиатуры — `Enter` или пробел на выбранном блоке |
| Закрыть описание | `Esc` или кнопка закрытия |
| Полный экран | `F` (или `А` в русской раскладке), кнопка `⛶`; также можно использовать `F11` браузера |
| Вернуться ко вступлению | `Home` или логотип Beget |
| Перейти к последнему событию | `End` |

События не перелистываются автоматически. Фоновая анимация работает независимо от переключения шагов и отключается, если в системе включено уменьшение движения.

На конкретный шаг можно сослаться через адрес, например:

```text
http://127.0.0.1:5173/#chapter-4-step-1
```

## Что показано в презентации

| Уровень | Роль |
| --- | --- |
| **L0 — управляющий кластер** | `ClusterClaim` задаёт целевую конфигурацию. ClusterClaim Operator координирует процесс, создаёт ресурсы `Cluster` и служебные компоненты CSR approver / CCM. Cluster API управляет созданием кластеров. |
| **L1 — инфраструктурный кластер** | Размещает инфраструктурные компоненты, Argo CD, AddonOperator и control plane L2 как приложение. Аддоны по фазам готовят защищённую платформу. |
| **L2 — клиентский кластер** | Предоставляет пользователю Kubernetes API и среду для приложений. Control plane L2 физически размещается в L1. |

Отдельно раскрыты взаимодействие с облаком и Vault, цепочка `AddonClaim → Addon → Applications → приложение` и передача статусов обратно по ресурсам. Подробности и реплики для выступления находятся в [сценарии ведущего](outputs/platform-beget-guide.md).

## Изменение и сборка

Редактируйте исходники в `src/` и HTML-оболочку `index.html`. Команды выполняются из корня репозитория:

```bash
npm run typecheck
npm run build
```

`npm run typecheck` проверяет типы без создания файлов сборки. `npm run build` также включает проверку типов, затем собирает сайт через Vite в `dist/` и экспортирует автономную презентацию в `outputs/platform-beget.html`. После пересборки обновите открытую готовую презентацию в браузере.

Чтобы локально посмотреть собранный сайт:

```bash
npm run preview
```

Откройте **[http://127.0.0.1:4173/](http://127.0.0.1:4173/)**. Если порт занят, используйте `npm run preview -- --port 4174` и адрес `http://127.0.0.1:4174/`. Сервер просмотра останавливается через `Ctrl+C`.

Для размещения на статическом хостинге отдавайте содержимое `dist/`. В нём находятся `index.html`, альтернативный вход `platform-beget.html`, каталог `assets/` и сценарий `outputs/platform-beget-guide.md`. Относительная база путей `./` позволяет разместить сборку в подкаталоге. Навигация хранится в hash (`#chapter-4-step-1`), поэтому правила перенаправления маршрутов не требуются. Production-серверу не нужен Node.js.

| Путь | Содержимое |
| --- | --- |
| `outputs/platform-beget.html` | Основная готовая презентация |
| `outputs/platform-beget-guide.md` | Сценарий и заметки ведущего |
| `outputs/platform-beget-preview.png` | Сохранённый предпросмотр |
| `index.html` | HTML-оболочка приложения |
| `src/main.ts` | Точка входа, навигация и взаимодействие с презентацией |
| `src/content.ts` | Главы, заголовки, пояснения и результаты событий |
| `src/graphs-a.ts`, `src/graphs-b.ts` | Блоки схем, связи и состояния шагов |
| `src/diagram.ts` | Отрисовка схем |
| `src/space.ts` | Космический фон и звездопад |
| `src/types.ts` | Общие типы данных презентации |
| `src/style.css` | Оформление |
| `src/assets/` | Логотип, шрифты и другие ресурсы приложения |
| `scripts/export-standalone.ts` | Экспорт автономного `outputs/platform-beget.html` |
| `dist/` | Результат сборки для статического хостинга |

Сценарий и PNG-предпросмотр — отдельные материалы: скрипт сборки не обновляет их автоматически.
